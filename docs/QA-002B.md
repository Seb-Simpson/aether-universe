Existing checks cover the four Saturn-system destinations, their camera/picking paths, focus transitions, zoom/reset, panels, keyboard/reduced motion and WebGL reading fallback.

Pages checks observe successful prefixed JavaScript, stylesheets, fonts and textures, and explicitly fetch the lunar manifest, collision grid, thumbnail and parent/fine terrain payloads. Normal lunar journeys reject console errors, page errors, HTTP failures and unprefixed local asset requests; expected request cancellation is distinguished from failure. The deliberate 503 test is isolated from these normal-path checks.

Visual inspection found and fixed tile-aligned shadow/lighting seams: skirts no longer enter shadow depth, and surface normals use a shared DEM apron rather than vertical skirt faces. Sun shadow targets, height/texture tiles, ImageBitmaps, geometry, materials and input listeners have explicit cleanup. The globe stays resident within a Moon session and is released on destination exit.

## Objective detail evidence

`data-detail.json` compares real elevations at identical canonical locations. The level-0 mesh omits up to 294.286 m of relief relative to the fine measured grid (25.417 m RMS); level 1 has 11.620 m RMS difference, level 2 5.184 m and level 3 2.171 m. Level 4 contains all canonical samples. This measures approximation error between LOD meshes, not source accuracy.

The browser also records selected tile levels, spacing, mesh sample counts, actual drawn triangles, resident tile bytes and renderer allocation counts at aerial and near-ground views. Sample counts mean active LOD-frontier tiles × 65², including duplicate edges and frustum-culled tiles; they are not unique source pixels or actual drawn vertices. Drawn triangles are recorded separately. Regional WAC imagery adds real approximately 100 m information beyond the globe map's approximately 1.3 km north/south sampling.

## Reproduction

```bash
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

Stop any server on port 3000 first; Playwright starts its own strict static server. To collect extended measurements, start `npm run start` in another terminal after building, then run:

```bash
node scripts/lunar-qa.mjs
node scripts/responsive-smoke.mjs
```

Open `http://localhost:3000/aether-universe/`, choose Moon → Approach region → Explore surface. Drag to look, hold WASD/arrows or the flight controls, use E/Q for height, and zoom/pinch to approach. Return to orbit restores the globe. Sources, offline processing, units and accuracy limits are documented in [LUNAR-DATA.md](LUNAR-DATA.md).

## Known limitations

- Only the 60 km Aristarchus region has measured terrain. Context outside it is a reference sphere, and the finite boundary can be apparent from high/peripheral views.
- Effective elevation detail is roughly 60–100 m; imagery is approximately 100 m. Low views expose smooth sampled slopes, soft image detail and baked acquisition shadows. No synthetic fine geology or metre-scale accuracy is claimed.
- New child meshes geomorph; rapid coarsening can still show small LOD transitions.
- Collision conservatively includes all parent meshes and maintains at least 45 m clearance. This can keep the camera above the finest mesh, especially on steep relief.
- Tile-cache limits exclude globe maps, shadow targets, mipmaps, driver overhead and the collision grid. Desktop 8k globe retention is about 128 MiB base RGBA (~171 MiB with mipmaps), mobile 4k about 32 MiB (~43 MiB with mipmaps).
- Physical phones, Safari/Firefox, screen-reader certification, sustained thermal/battery behaviour, and long-duration browser/process memory profiling were not tested. No physical-device FPS claim is made.
- This PR is not merged or deployed; the public main site continues its existing release.
