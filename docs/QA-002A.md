# AETHER-002A verification

## Audit and baseline

The feature branch starts at main `93503a12149e23a990336a54e4a68175a11fde4b`. PR #1 (foundation) and #2 (Pages) were open and unmerged at audit time. The existing Pages workflow exports Next.js to `out/` and deploys only main; the feature branch does not publish or change that live site.

Baseline browser validation ran against the anonymous public HTTPS site, not a development server: **10/10 existing interaction journeys passed** (2.7 minutes). Captures use Chromium software WebGL, DPR 1, at matching desktop 1440×1000, mobile 412×915 and narrow-phone 360×800 CSS viewports. Before evidence is under `docs/screenshots/002a/before-*.png` and `before-metrics.json`.

| Baseline | Document height | Viewport height | Canvas size | Renderer allocations |
| --- | ---: | ---: | --- | --- |
| Desktop | 1864 | 1000 | 1065.6×650 | 6 geometries / 8 textures |
| Mobile | 2804 | 915 | 412×430 | 6 geometries / 8 textures |
| Narrow phone | 2819 | 800 | 360×430 | 6 geometries / 8 textures |

The initial main-pass renderer counters were 22,048 triangles on desktop and 19,072 on the two phone viewports. Viewport composition and frustum visibility affect these counters; they are not GPU frame-time measurements.

## Changed-behavior regressions

The prior landing-page tests have been adapted to the immersive interface, retaining selection, camera controls, sourced facts, reduced motion and WebGL failure checks. Additional checks cover no document scrolling with panels/menus open, full viewport canvas, direct mouse/touch orbit, release retention, wheel/pinch zoom, detail-aware near limits, collision clearance, keyboard camera navigation, repeated subject transitions and bounded LOD allocation.

Pages asset checks now fetch through the browser instead of Playwright's Node API client so the same probe works through the execution environment's proxy and matches actual application traffic. Actual scripts, CSS, bundled font and maps must load beneath `/aether-universe/` without request failures.

### Rendering observations

`docs/screenshots/002a/after-metrics.json` records the supplementary measurements. The tablet overview reports 19,792 main-pass triangles; the narrow-phone overview reports 5,440, with the latter using a medium Saturn and low moon geometry. The prior narrow-phone view reported 19,072. This is an observation of different viewport compositions/LOD/frustum visibility, **not** a same-camera GPU speedup benchmark. Deterministic per-mesh geometry reductions and typed-array budgets are documented separately in RENDERING-002A.md.

Geometry counts warm to **5**, then stay at 5 through twelve complete subject changes per supplemental viewport; texture counts remain **8**. The narrow initial count of 4 becomes 5 on first use of another shared tier, as expected. Idle frame counters remain 2→2 over the one-second observation and canvas screenshots are byte-identical. Resource pools/listener teardown was reviewed, and real context-loss tests unmount the canvas while preserving the HTML interface. These checks do not substitute for a sustained heap profiler or real-device GPU measurement.

### Implementation defects caught before delivery

The original layout hid the mobile information button while its panel was open; synchronous focus restoration could therefore run before that button became visible. Restoration now waits for the DOM update. Camera integration also explicitly pauses transfers beneath native dialogs, anchors an interrupted transfer on the selected body, and checks the final eye position after OrbitControls angle adjustments. Unit tests and the final browser regressions cover these behaviors.

No known functional defect remains in the executed journeys. No terrain/landing implementation was attempted. The existing public Pages deployment remains on main and is not replaced by this feature branch.

## Reproduction

```bash
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

Playwright starts the dependency-free static export server at `http://127.0.0.1:3000/aether-universe/`. It does not run a Next development/runtime server. Stop any existing process on port 3000 first. For supplementary tablet/narrow-phone idle, LOD and resource checks, start `npm run start` in one terminal and run `node scripts/responsive-smoke.mjs` in another.

## Limits

Chromium desktop/mobile emulation and software WebGL do not certify physical-device GPU performance, sustained battery/thermal behavior, Safari/Firefox, or screen-reader operation. Allocation counts and idle frames identify obvious resource churn or unintended animation, not every possible heap leak. No terrain, surface landing, true-scale orbit model or scientific terrain accuracy is claimed.
